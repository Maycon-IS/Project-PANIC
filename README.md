# 💣 Last Fuse (code-nome: PANIC) 

> Corra. Dê Dash. Passe a bomba. Sobreviva.

Last Fuse é um Party Game 2D desenvolvido na Unity, inspirado em jogos como **Stick Fight**, **Move or Die** e **Ultimate Chicken Horse**.

O objetivo é simples: não fique com a bomba quando o tempo acabar.

Enquanto os jogadores tentam passar a bomba uns para os outros, a arena muda constantemente com eventos, obstáculos e perigos que tornam cada partida imprevisível.

---

## 🎮 Gameplay

- 💣 Passe a bomba antes da explosão.
- ⚡ Utilize o Dash para escapar ou perseguir adversários.
- 🌋 Sobreviva aos eventos da arena.
- 🏆 Seja o último jogador vivo.

---
